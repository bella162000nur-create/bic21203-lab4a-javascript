## Lab Objectives
To develop interactive web pages using JavaScript functions, event handling, input validation, loops and DOM manipulation.

## Lab Activities

### Question 1  Interactive Text Changer
Created a webpage that changes the paragraph text from "Welcome to my website!" to "Hello there!" when the user clicks the Change Message button.

**JavaScript concepts:** DOM selection, functions and event listeners.

### Question 2  Smart Number Validator
Created an interactive number validator that accepts user input and displays whether the number is lower than, higher than or equal to 10. Invalid or empty inputs display an appropriate error message.

**JavaScript concepts:** Variables, Number conversion, conditions (if...else if...else) and input validation.

### Question 3  Dynamic Number Generator
Created a webpage that generates an ordered list of numbers from 1 to 5 when the Generate button is clicked. Existing list items are cleared before generating new ones.

**JavaScript concepts:** For loops, document.createElement(), textContent and appendChild().

## Project Structure

## How to Run
1. Download or clone this repository.
2. Open the project folder using Visual Studio Code.
3. Open the required question folder (Q1, Q2 or Q3).
4. Open `index.html` in a web browser or using Live Server.
5. Interact with the buttons and test the outputs.
